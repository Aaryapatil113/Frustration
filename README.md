# Stress-Aware Interface: Course Registration Demo

An HCI class project by **Git Girls** (Akshiya Vaibhavi Saravanan, Deeksha Manjunatha Bankapur, Aarya Prashant Patil), Northeastern University.

**Live demo:** https://aaryapatil113.github.io/Frustration/

A fake Spring 2027 course registration page in two versions:

- **Regular:** full of real-world frustrations, like unclear errors, hidden rules, timers and pop-ups.
- **Stress-aware:** notices frustration from typing, deleting, mouse movement and mistakes, then makes the task easier **without skipping any steps**.

## How it works

1. **Watch** typing, deleting, mouse movement and mistakes
2. **Score** stress from 0 to 100
3. **Help** with clearer messages, fixed formats, saved work and fewer pop-ups
4. **Pause** by offering a short break if stress stays high

Every change is shown to the user and can be undone.

## Quick links

- `?v=frustrating` opens the regular version
- `?v=adaptive` opens the stress-aware version
- `?meter=1` shows the live stress meter

## Privacy

Only timing is measured. What people type is never recorded.
